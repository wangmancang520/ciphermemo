# 安全设计与运行边界

[返回项目首页](../README.md) · [架构说明](ARCHITECTURE.md) · [安全问题反馈](../SECURITY.md)

CipherMemo 当前版本为 0.1.0，面向个人使用，尚未经过独立安全审计。首次上线请先用非关键演示内容验证登录、备份和恢复流程。

## 加密设计

| 环节       | 实现                                                         |
| ---------- | ------------------------------------------------------------ |
| 密码派生   | Argon2id，64 MiB 内存、3 次迭代、并行度 1、16 字节随机盐     |
| 用途隔离   | HKDF-SHA-256，分别派生登录凭证和密码包装密钥                 |
| 内容密钥   | 随机 256 位数据密钥，通过密码包装密钥加密保存                |
| 内容加密   | AES-256-GCM，每次使用随机 96 位 IV                           |
| 上下文绑定 | 附加认证数据绑定协议版本、对象 ID；文件还绑定分块顺序        |
| 文件传输   | 4 MiB 明文分块独立加密，校验分块数量和原始总长度             |
| 恢复机制   | 独立随机恢复密钥，分别派生恢复凭证与恢复包装密钥             |
| 可信设备   | IndexedDB 中的不可导出 Web Crypto 设备密钥，加密保存数据密钥 |

密码的盐和参数公开保存。登录凭证是可重放的 bearer secret，仅通过 HTTPS 请求体发送，服务端保存其 SHA-256 校验值。本方案不是 PAKE，仍然信任首次加载的网页代码和 HTTPS 通道。

随机数据密钥只在浏览器解锁后可用。正文、凭据、昵称、附件元数据、头像和文件内容在浏览器内加密。恢复密钥使用独立包装，忘记密码时可在浏览器重新包装同一数据密钥。

修改密码会递增账号版本、撤销现有会话，并重新包装数据密钥；原恢复密钥保持有效。当前版本没有全空间数据密钥轮换功能。

## 会话与可信设备

- 临时设备不持久保存解锁材料；前端 5 分钟无操作会锁定。服务端临时会话 30 分钟无请求失效，最长 24 小时。
- 可信设备由用户主动勾选，在固定 14 天内免输密码；服务器账号版本和会话必须仍然有效。
- 拥有该浏览器配置的人，可能在可信期内直接打开空间。不要在公共设备上启用信任。
- 远程撤销会阻止后续在线访问，不会收回已经下载的内容或擦除离线设备。
- 浏览器关闭或退出时仅能尽力释放内存引用，不能保证清除系统内存、剪贴板、浏览器残留或恶意扩展读取的副本。

## 服务端能看到什么

数据库保存内容密文。服务器仍可见登录邮箱 / 旧账号标识、对象数量、时间、密文长度、置顶与回收站状态、会话设备名称、头像引用和其他必要索引。

浏览器负责全文搜索，当前版本加载空间内全部文本并在解密后搜索；附件按需读取。

## 客户端信任边界

如果浏览器、扩展、设备或部署的前端代码被控制，加密不能保护正在解锁的内容。不可导出的 CryptoKey 不代表硬件保护。项目的会话校验、来源检查、HTTPS、内容净化与响应头不能替代可信客户端环境。

如果旧密码与旧数据密钥包装同时泄露，仅修改密码无法撤回旧密钥。此时应结合个人风险评估迁移内容；当前版本不提供数据密钥轮换操作。

## 保存、并发与恢复

并发编辑采用乐观版本控制；其他设备更新后会拒绝覆盖，当前编辑可另存为副本。保存失败时，未确认成功前应保持页面打开。

锁定前可在当前页面内暂存未保存编辑的密文，重新登录后恢复为副本；这份暂存只在内存中，关闭页面会丢失。

个人信息也使用版本校验。当前使用的头像受到删除保护；替换或移除后旧图可以清理。头像与普通附件使用相同的私有 R2 加密存储流程，不提供公开图片地址。

## 备份策略

- 恢复密钥保存在本空间之外；不要把唯一副本放回这个空间。
- 定期导出加密空间备份，包含条目、回收站、附件和个人信息。
- 保留**导出当时的密码**。修改当前密码不会更新旧备份。
- 导入会创建条目副本，可能因网络失败部分完成；重复导入前查看已完成部分。
- 导入到尚未设置个人信息的空间时恢复昵称与头像；已有个人信息保持不变。
- 本版没有一键导出全部明文内容的功能。附件可以逐个在浏览器解密后下载。
- D1 与 R2 的平台备份需分别考虑，不要仅依赖数据库恢复。

## 容量与文件边界

普通附件不设置应用层单文件或空间配额，不代表物理无限或免费无限。Workers、D1、R2、浏览器内存与平台账单均有边界。头像支持 JPG、PNG、WebP、AVIF，最大 5MB。

长正文存储在 D1 单行，受其行大小限制。分块传输避免在 Worker 内一次处理完整大文件，但下载和备份目前仍会在浏览器内组装完整 Blob / JSON；大文件、大空间受设备内存限制。

当前版本没有流式写入本地文件系统、跨刷新断点续传或自动图片缩略图。5GB 进度条只是视觉参考，不会阻止超过基准的普通内容保存。

用量统计涵盖内容负载、加密封装、附件元数据、回收站和待处理上传；不含数据库索引、孤立 R2 对象清理前的短暂开销等全部平台成本，不等于完整计费量。

## 清理与部署运维

每日 Cron 清理过期回收站、未完成上传、废弃头像与会话，并分批核对孤立 R2 分块。删除可重试，但 D1 与 R2 之间没有跨服务原子事务。

R2 保持私有，不要开启公共访问。`.dev.vars`、环境密钥、空间备份和私人内容不应提交到仓库。默认关闭 Worker 请求日志；自行开启监控时，不要记录请求体、Cookie、凭证或文件内容。
